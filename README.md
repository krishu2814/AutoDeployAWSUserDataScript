# AWS EC2 Deployment Guide

This guide explains how to deploy an application on an AWS EC2 instance using Git and PM2.

---

# Prerequisites

Before deployment, ensure you have:

* AWS Account
* EC2 Instance
* SSH Key Pair (`.pem`)
* Source Code Repository

---

# 1. Launch an EC2 Instance

1. Open AWS Console.
2. Navigate to EC2 Dashboard.
3. Click **Launch Instance**.
4. Select Ubuntu Server.
5. Choose an instance type.
6. Create or select a key pair.
7. Configure Security Groups.

Allow the following inbound rules:

| Type       | Port                  |
| ---------- | --------------------- |
| SSH        | 22                    |
| Custom TCP | Your Application Port |

Example:

| Type       | Port |
| ---------- | ---- |
| SSH        | 22   |
| Custom TCP | 5000 |

8. Launch the instance.

---

# 2. Connect to the Server

```bash
chmod 400 your-key.pem

ssh -i your-key.pem ubuntu@YOUR_PUBLIC_IP
```

---

# 3. Update the Server

```bash
sudo apt update

sudo apt upgrade -y
```

---

# 4. Install Node.js

```bash
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -

sudo apt install -y nodejs
```

Verify installation:

```bash
node -v

npm -v
```

---

# 5. Install Git

```bash
sudo apt install git -y
```

Verify installation:

```bash
git --version
```

---

# 6. Clone the Repository

```bash
git clone <repository-url>
```

Move into the project directory:

```bash
cd project-name
```

---

# 7. Configure Environment Variables

Create a `.env` file:

```bash
nano .env
```

Add all required environment variables.

Save and exit.

---

# 8. Install Dependencies

```bash
npm install
```

---

# 9. Build the Application (If Required)

```bash
npm run build
```

Skip this step if your project does not require a build process.

---

# 10. Install PM2

Install PM2 as a project dependency:

```bash
npm install -g pm2
```

---

# 11. Start the Application

If your project has a start script:

```bash
npx pm2 start npm --name app -- start
```

Or if starting a specific file:

```bash
npx pm2 start server.js --name app
```

---

# 12. Verify Application Status

```bash
npx pm2 list
```

View logs:

```bash
npx pm2 logs
```

---

# 13. Save PM2 Configuration

```bash
npx pm2 save
```

---

# 14. Enable Auto Restart After Reboot

```bash
npx pm2 startup
```

Run the command generated by PM2.

Then execute:

```bash
npx pm2 save
```

---

# 15. Access the Application

Open:

```text
http://YOUR_PUBLIC_IP:PORT
```

Example:

```text
http://13.232.xxx.xxx:5000
```

---

# Deploying New Changes

Connect to the server:

```bash
ssh -i your-key.pem ubuntu@YOUR_PUBLIC_IP
```

Navigate to the project:

```bash
cd project-name
```

Pull latest changes:

```bash
git pull origin main
```

Install dependencies:

```bash
npm install
```

Build application if required:

```bash
npm run build
```

Restart application:

```bash
npx pm2 restart app
```

---

# Useful Commands

## Check Running Applications

```bash
npx pm2 list
```

## View Logs

```bash
npx pm2 logs
```

## Restart Application

```bash
npx pm2 restart app
```

## Stop Application

```bash
npx pm2 stop app
```

## Delete Application

```bash
npx pm2 delete app
```

## Monitor Application

```bash
npx pm2 monit
```

## Check Memory Usage

```bash
free -h
```

## Check Disk Usage

```bash
df -h
```

## Check Running Processes

```bash
ps aux
```
